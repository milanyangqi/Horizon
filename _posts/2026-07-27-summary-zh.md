## [Decker：受 HyperCard 和经典 macOS 启发的现代平台](https://beyondloom.com/decker/) ⭐️ 7.0/10

Decker 是一个新推出的平台，它继承了 HyperCard 和经典 macOS 的遗产，为直观的应用开发提供了现代化的环境。 Decker 之所以重要，是因为它满足了市场对 HyperCard 现代化版本的渴望。它可能为应用开发提供一种用户友好的替代方案，特别是对于那些重视开发工具简单性和灵活性的人来说。 Decker 旨在重现 HyperCard 提供的易用性和灵活性，并结合现代技术和界面设计的优势。它的设计目标是成为一个直观的平台，用于创建应用程序，无需广泛的编码知识。

hackernews · tosh · 7月26日 18:23 · [社区讨论](https://news.ycombinator.com/item?id=49060856)

**背景**: HyperCard 是 Macintosh 电脑上的一个早期超媒体系统，允许用户创建交互式应用程序。它以其简单性和内置的编程语言 HyperTalk 而闻名。经典 macOS，也称为 Mac OS，是 1984 年至 2001 年 Macintosh 电脑上的一系列操作系统，以其图形用户界面和对现代计算的影响而著称。

## [美国公民使用胁迫密码清除手机被起诉](https://www.techspot.com/news/113236-us-prosecutors-charge-atlanta-man-after-grapheneos-phone.html) ⭐️ 7.0/10

一名美国公民在机场检查时使用胁迫密码故意清除其 GrapheneOS 手机后被起诉。 这个案例之所以重要，是因为它突显了使用胁迫密码等安全特性可能带来的法律后果，这可能影响隐私和安全讨论。 胁迫密码是一个安全特性，允许用户通过输入替代密码故意清除他们的设备，这在此次事件中被使用。

hackernews · eecc · 7月26日 22:21 · [社区讨论](https://news.ycombinator.com/item?id=49063022)

**背景**: GrapheneOS 是一个专注于安全和隐私的开源移动操作系统，提供了如胁迫密码等功能。胁迫密码是个体在被胁迫时使用的一种隐蔽信号，允许他们在不引起怀疑的情况下触发特定动作，例如清除设备。

## [调查揭示中继市场推动代币转售和欺诈行为](https://simonwillison.net/2026/Jul/26/relay-market/#atom-everything) ⭐️ 7.0/10

Matt Lenhard 对围绕通过汇集各种来源的 API 密钥以折扣价转售 LLM 代币而兴起的市场进行了引人入胜的调查，这主要发生在中国。 这项调查意义重大，因为它突出了在 API 和代币经济中滥用免费试用、通过未受保护的支持机器人代理以及盗用信用卡的问题，这引发了安全和欺诈方面的担忧。 这个市场中使用的代理是开源软件，主要是'one-api'及其分支'new-api'，这些是合法的 API 代理产品，用于在一组 API 凭证中负载均衡请求。
