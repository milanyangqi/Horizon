## [Nativ：在 Mac 上本地运行前沿开放模型](https://blaizzy.github.io/nativ/) ⭐️ 7.0/10

由'Prince Canuma'开发的 MIT 许可证应用 Nativ，允许用户在 Mac 上本地运行前沿开放模型，利用开发者在 MLX-VLM 方面的专长以实现更快的推理速度。 Nativ 的重要性在于它可能为开发者和研究人员提供一种更便捷、更高效的方式来在苹果设备上本地部署先进的 AI 模型，这可以加快开发周期，并减少对云服务的依赖。 该应用利用了 MLX-VLM，这是一个在苹果设备上比其他库如 llama.cpp 更快推理速度的包，并且由同一开发者维护，表明了高水平的专业知识和潜在的可靠性能。

hackernews · aratahikaru5 · 7月20日 18:16 · [社区讨论](https://news.ycombinator.com/item?id=48982681)

**背景**: MLX-VLM 是一个使用 MLX 在 Mac 上进行视觉语言模型(VLMs)推理和微调的包，它是与 CUDA 相比规模较小但更新迅速的社区的一部分。Nativ 的引入旨在弥合本地部署尖端模型的需求与苹果硬件能力之间的差距。

## [Jelly UI：为原生 HTML 表单控件引入软体物理动画](https://jelly-ui.com/) ⭐️ 6.0/10

Jelly UI 为原生 HTML 表单控件引入了软体物理动画，引发了关于性能和用户体验的混合反应和讨论。 将软体物理动画引入表单控件之所以重要，是因为它代表了 UI 设计的一种新颖方法，可能增强视觉吸引力。然而，对性能和遵循 UX 最佳实践的担忧突显了 Web 开发中创新与实用性之间的权衡。 Jelly UI 在页面上的每个组件运行每 8 毫秒一次的 RAF 动画循环，导致整个文档重新绘制。这种虽然视觉上独特，但引发了性能方面的担忧，特别是在功能较弱的设备上。

hackernews · baldvinmar · 7月20日 17:07 · [社区讨论](https://news.ycombinator.com/item?id=48981620)

**背景**: Jelly UI 是一个 JavaScript 库，它将软体物理动画应用于原生 HTML 表单控件。这种技术旨在创建一个更具动态性和视觉吸引力的用户界面。软体物理指的是模拟柔性、可变形材料，可以应用于数字界面以模仿物理对象的行为。

**社区讨论**: 社区对 Jelly UI 的看法不一。一些用户欣赏其新颖性和创造力，而其他用户则对性能和遵循 UX 最佳实践提出了担忧。还有建议允许用户在不改变系统偏好设置的情况下覆盖减少运动设置。

**标签**: `#UI`, `#Animation`, `#HTML`, `#Performance`, `#User Experience`
